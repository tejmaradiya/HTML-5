Question 1: What is the difference between HTML and HTML5?
Answer:
HTML is the standard markup language used to create web pages, while HTML5 is the latest version that includes new features like semantic tags, audio/video support without plugins, improved form controls, and APIs for modern web development.


Question 2: What are the additional tags used in HTML5?
Answer:
HTML5 introduced new semantic and multimedia tags such as:

<header>, <footer>, <section>, <article>, <nav>

<audio>, <video>, <source>

<canvas>, <svg>

<figure>, <figcaption>, <main>, <mark>

These tags improve page structure and support modern web features.
